## Materials held in Drive

Private correspondence, newly filed individual evaluations, reviewer annotations, course recordings, other students' coursework, and materials with unconfirmed redistribution rights stay in Drive. Public source cards in the Chapter 2 exemplars folder identify the underlying publications. The full editions supplied for this research remain available to authorized Drive readers.

The writing-guidance index and three SatNOGS provenance or reproducibility files have explicitly labeled public copies. Those copies remove private mailbox links or correspondence. The v05 package's input checksum list identifies the public provenance file. Scientific inputs, code and original validation outputs keep their source bytes. The authoritative packages and their original checksums remain in Drive.

## File verification

The public inventory lists SHA-256 for the bytes readers can download. For native Google documents and slides, the checksum identifies the exported Office file. For large release assets it identifies the original media, while the Git blob column identifies the download note in the folder. A repeated row can represent a separate Drive file with the same name, path and contents.
