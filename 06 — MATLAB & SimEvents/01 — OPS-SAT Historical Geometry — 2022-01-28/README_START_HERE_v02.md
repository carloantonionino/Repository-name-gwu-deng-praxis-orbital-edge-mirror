## What changed from v01

The user supplied **`sat000044878.txt`**, a 1,512-byte, nine-set historical TLE/3LE attachment for OPS-SAT (NORAD **44878**, COSPAR **2019-092F**), covering January 26–30, 2022. All 18 numbered TLE lines pass checksum validation. The original data are preserved unmodified in this package.

**Nine historic sets** were parsed; the TLE with epoch **2022-01-28T10:54:30.938400+00:00** is nearest the ACE midpoint **2022-01-28T17:48:34+00:00**, by **6.901 hours**. The derived 3-line `OPS_SAT_44878_SELECTED_2022-01-28.tle` is generated by selecting the closest valid set; it does not interpolate the orbit. No element was invented. The script reselects from the original uploaded file at execution time and checks the NORAD ID, epoch, source witnesses and TLE checksums.

## Fixed experiment identity

- **Only one spacecraft:** ESA OPS-SAT, 44878; do not add other spacecraft without independently qualified source observations.
- **ACE geometry window:** 2022-01-28 17:42:49–17:54:19 UTC; 690 seconds, using 1-second geometry samples.
- **100 accepted source witnesses**, only **10** with recorded station IDs (4 for ESTEC 839; 6 for DL5FAB 2504). The remaining 90 are observer-/locator-only (EA6TC 46, EU1XX 44); their station identities are not promoted into exact station IDs by inference.
- Site coordinates and minimum elevations are based on currently published station profiles. **Historical January 2022 coordinates/configurations have not been independently verified**. EU1XX remains an approximate Maidenhead cell only and is not used for quantitative access.
- The geometric access and comparison results are *predictions* from SGP4 and the current site coordinates; they must be checked against timestamped radio reception evidence, and are not measured link availability or packet loss.

## Run in MATLAB

Extract the ZIP into a new MATLAB working directory **without overwriting the original `MATLAB_Baseline2_Simultaneous_ACE`**. Set MATLAB Current Folder to the extracted directory and run:

```matlab
ver
which satelliteScenario -all
which satellite -all
praxis_ops_sat_historical_geometry_v02
```

Expected preflight: **100 witnesses associated with NORAD 44878; 9 valid TLE pairs; chosen TLE epoch 2022-01-28 10:54:30 UTC**, then a 3D viewer and station access CSVs. The script compares 10 station-ID-verified radio-witness times against the computed visibility intervals. A disagreement should be investigated, not masked.

MATLAB `satelliteScenario`, `satellite`, `groundStation`, `access` and `satelliteScenarioViewer` must be installed/licensed. `ver` and `which` will diagnose missing functions. Satellite Communications Toolbox and Aerospace Toolbox expose relevant functionality depending on installation/license configuration. MATLAB UI/visualization execution was not tested in this environment.

**IMPORTANT:** keep the old fixed 600-up/120-down DES model unchanged; this geometry is a separately versioned experiment until geometry/access validation is complete.
